Non-negotiable boundaries

  • Cordis remains process-local composition infrastructure.
  • Shared domain contracts remain platform, UI, React, and Cordis independent.
  • UI plugins read projections and dispatch actions only.
  • Terminal, file, media, buffer, and reliable-input bodies use dedicated data streams.
  • Control/debug/routing/retry/health semantics stay outside business payloads.
  • No fallback, shadow route, second owner, or copied runtime source.
