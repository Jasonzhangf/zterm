# Mac Function Map

## Purpose

This file is the Mac desktop workspace owner registry. Use it before changing Mac workspace, runtime, server, file, or Electron window code.

Rules:

- `binding pending` means the target owner is not implemented yet. Do not invent symbols.
- Current transitional symbols are listed only to locate debt; they are not final owners.
- Runtime/session/buffer truth must stay outside workspace records.
- Server/session projection refresh must not mutate workspace tabs.
- File preview policy belongs to shared file-browser core, not Electron IPC or React UI.

## Current Transitional Debt

- `MacWindowManager` now owns BrowserWindow create/focus/restore, persisted open window records, New Window menu/IPC, and renderer `windowId` query injection. Packaged smoke restored the same two window IDs after quit/reopen under `mac/evidence/2026-07-04-window-manager-smoke/`.
- `MacWorkspaceStore` pure owner now exists under `mac/src/app/workspace/workspace-store.ts`; production renderer uses `windowId` from the Electron load query to load/save window-scoped workspace records through `MacAppShell`.
- `MacRuntimeRegistry` now owns runtime creation/connect/activity for the current production path; packaged A/B tmux input/resize/switch/close isolation smoke passed under `mac/evidence/2026-07-04-runtime-live-isolation-smoke/`.
- `LocalTmuxManager` owns Electron-side local tmux capture/input/head/sync. Its canonical normal-screen capture must include scrollback and visible pane bottom; alternate-screen TUI capture must use current screen truth instead of full-history payload. The packaged terminal buffer gate is the L5 proof that app rendered rows match tmux truth.
- `MacPaneWorkbench` still contains nested `MacTerminalPane`; extraction to a terminal owner path remains pending.
- Legacy `ShellWorkspace` all-in-one source has been physically removed after replacement coverage passed. Schedule, screenshot, file-transfer, QuickConnect, Details, and Terminal primitives remain only as standalone components/protocol helpers for future owner slices, not as a production workspace fallback.
- `MacServerDirectory` now provides a production left server rail for saved server/session projection and read-only daemon live refresh. Refresh remains projection-only: it updates live snapshot/status/error state and never creates, closes, or prunes workspace tabs.
- `ConnectionLauncher` / `QuickConnectSheet` remain add/edit/manual connection surfaces, not the persistent server projection owner.
- `FileBrowserCore`, `MacFileBrowserPanel`, and `mac/electron/file-system.ts` now own the local file browser branch; packaged fs smoke passed under `mac/evidence/2026-07-04-file-browser-smoke/`.
