# Confirmed terminal daemon buffer and renderer contract

The daemon owns canonical absolute-row terminal truth and no client state. Every logical body publication is a contiguous absolute range, while the client cache may be sparse. The target client buffer is a configurable absolute-row rolling window with a 3000-line default; this decision does not define its maximum. Initial connection is head/tail first, then a contiguous catch of at most three screens; older history is on demand. Reconnect preserves useful in-range cached rows. Renderer owns visible range, follow, reading and renderBottomIndex; buffer owns hole detection and range repair. Stable/live is not a client buffer or renderer layer, and the daemon cannot lock stable TUI rows because it does not own reflow truth.
