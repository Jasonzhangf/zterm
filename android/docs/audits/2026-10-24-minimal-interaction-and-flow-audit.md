# 最小交互与流程审计（2026-10-24）

本轮覆盖 CLI、Android、Mac、Windows 的交互入口、反馈归属及开发交付流程。结论来自当前调用关系、独立观察和受影响入口验证。静态审计覆盖不代表所有平台已完成实机验收。

## 判断边界

每个步骤须改变用户决定、保护数据、表达当前状态或提供恢复入口。同一操作、同一作用域的同一结果由一个界面 owner 展示。远端错误、本地权限错误、逐文件进度和终端连接错误属于不同作用域，不能仅因同时出现而合并。破坏性操作确认、稳定身份校验、并发写保护及资源释放保留。

## 交互阶段

| 阶段 | 结论与处理 |
| --- | --- |
| 登录、账号、服务器配置 | 保留登录态和失败原因。CLI 登录成功只输出账号与 Relay 地址，没有观察报告所称的内部 generation 输出；不作虚假修复。 |
| 配置槽位、选择与预览 | 把独立的“预览 snapshot？”确认并入一个动作菜单。保存无需先拒绝预览。预览仍按需抓取，完成后可继续预览、重选 session、返回服务器、保存或退出。 |
| 槽位列表与启动选择 | 每行仅显示槽位号、可选别名和一次“服务器 / session”。移除常规列表的 backend、宽度枚举和重复名称。槽位号承担唯一选择身份，内部绑定仍使用精确稳定身份。session 选择器保留必要的 backend/路由上下文。 |
| 终端连接、恢复与输入 | 保留连接状态、错误和路由恢复入口。紧凑的链路活动及 backend 上下文有判断作用，不以减少字数为由删除。未改输入、transport 或 buffer 真源。 |
| 文件浏览与传输 | Android 的远端目录错误、本地权限/列表错误、预览保存状态及逐文件进度各有作用域，保留。Windows 大文件预览确认保护资源使用，保留。Mac 文件传输尚未接入主工作台属于既有能力缺口，本轮不扩成新功能。 |
| 远程窗口 | 保留关闭确认和输入结果边界。未对所有平台的远程窗口输入执行实机回归，不据静态读取声称端到端可用。 |
| Windows session 关闭 | 远端关闭会终止 session，补一次行内确认；取消不发送关闭。关闭本地标签页不增加确认。失效目标不保留待确认状态。 |
| Windows 操作错误 | session 控制错误只由侧栏展示；状态栏继续拥有终端错误。已由 controller 发布的拒绝在调用边界处理，不复制错误状态，不吞本地成功回调的异常。 |
| 更新与退出 | CLI 保留显式升级入口和独立退出组合键。Mac/Windows 自更新界面缺口如实保留，不新增成功提示来暗示能力存在。 |

## 架构消融

删除无人调用的 `useTerminalPageOverlays.ts` 及其独占测试，移除 feature registry 的过期路径。生产 overlay 状态仍由 `TerminalPage.tsx` 与现有 shell owner 持有。删除前的 import、barrel 和动态引用检查未发现生产消费者；活跃消费者测试继续覆盖截图、调度和 quickbar。历史审计记录保留。

本轮未改变业务图拓扑。槽位动作循环位于现有 `cli-slot-configure` 的导航算子内；Windows 反馈仍在 sidebar/statusbar 投影边界内；删除的 hook 不在活跃执行链上。复用现有闭合图，不为文档或节点内部交互另造治理图。

## 开发与交付流程消融

- 项目 Skills 按受影响表面选择构建和验收。CLI、daemon 或纯文档变更不再因仓库含 Android/Mac 而强制产生 APK 或 Mac 应用包。
- Android 行为变更仍执行适用的 L5、构建同步与设备交付要求。安全、文件字节正确性、真实错误及实际发布完整性检查保留。
- 移除普通工作中的冻结、重复哈希对账、固定证据数量、强制多路日志及重复汇报模板。正式安装仍验证实际入口和用户可见行为。
- 已有证据在输入和结论未变时直接复用。不为状态答复重新同步多份文件，不为每次编辑另开审查。
- registry、map 和边声明只在实际 owner、资源、边或契约变化时更新。保留项目现有边界检查，不建立第二套注册表。
- CLI 可配置 tmux socket 的文档明确标注为未实现设计；不把未来命令列成当前可用功能。

## 验证与范围

删除 overlay 已通过 feature registry、Android 类型检查和四组活跃消费者测试。CLI 0.1.4 已通过安装后的完整用户路径，以及槽位列表与启动选择器的同标签验证。真实 Windows 包已通过关闭/取消、错误单次投影和本地标签页关闭验证；验收使用独立 loopback daemon fixture，未操作用户 session。截图发现的窄侧栏确认按钮换行已调整布局。详细结果由本轮交付记录保存。

本轮没有调整用户 daemon、tmux server、Collab 或 Android 活跃行为。全项目静态覆盖发现的既有能力缺口不等于本轮修复，也不等于实机验收完成。
