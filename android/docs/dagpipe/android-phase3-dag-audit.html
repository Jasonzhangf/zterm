DAG 链路（中文业务语义）

输入执行链（daemon.input_schedule）
  1. 频道输入到达
  2. 入队去重并确认
  3. 写回后端正交执行
定时调度链（daemon.input_schedule）
  1. 读取调度源与调度策略
  2. 排定可执行计划
  3. 触发调度
  4. 分派到后端正交执行
文件浏览（daemon.file_transfer_browse）
  1. 校验目录浏览权限与路径
  2. 读取远端目录列表
  3. 投影为客户端浏览视图
文件上传（daemon.file_transfer_upload）
  1. 校验上传意图与传输策略
  2. 上传一个分段
  3. 返回分段回执
  4. 标记上传完成或失败
文件下载（daemon.file_transfer_download）
  1. 校验下载意图与传输策略
  2. 读取一个远端分段
  3. 返回分段回执
  4. 标记下载完成或失败
附件投递（daemon.attachment_delivery）
  1. 校验附件请求与投递策略
  2. 入队附件
  3. 投递到目标设备
  4. 发布投递回执；回执不等于目标消费
远端截图（terminal.remote_screenshot）
  1. 校验截图请求与权限
  2. 捕获远端截图
  3. 保存截图结果

状态机与失败终点

  • 输入项：pending → acknowledged → written，或 pending → nack；一次写后端一次。
  • 上传：validating → uploading → ack-segment → complete / failed。
  • 下载：validating → downloading → chunk-received → complete / failed。
  • 附件：validated → enqueued → delivered → receipt published；delivered 不代表客户端已消费。
  • 截图：validated → captured → result ready / failed。
  • 调度：planned → fired → dispatched；交互输入与定时调度互不串联。
