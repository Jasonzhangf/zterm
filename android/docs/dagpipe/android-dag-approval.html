规则 语义
一个目标一条物理连接 同一 daemon 目标只建立一个物理 transport；多个 session 是逻辑通道，不新建每 session socket。
账号登录 Relay 登录是账号级、token-per-login；登录失败或退出不得隐藏已保存的直连 / Tailscale 目标。
维持与恢复 心跳、网络变更、重连与退避属于目标连接角色；foreground / background 只改变数据刷新节奏，不重建健康连接。
单 / 多 session 单 session 只有一条通道；多 session 每条通道独立 open/close、body 订阅、head/range lane，一个通道失败不连坐其它通道。

状态 语义
每 session 独立 absolute-row truth、revision epoch、缺口 repair、repair ledger 都按 session 隔离。
active / inactive active 高频 head-first；visible passive 有界轮转；inactive 停止主动拉取但保留 buffer truth，不关 transport。
正文 repaint 只有完整无洞 frame 的 sparse apply 可以进入 render scope；head / cursor 只更新 metadata。
repair ledger 未实际写 wire 保持 pending；dispatch 后保留；权威覆盖或显式 epoch reset 才清除。

规则：normalizer 只做纯文本归一；可靠输入队列唯一持有 seq / ACK / retry； 最终输出走当前 mux channel，不替换物理 transport。

状态机与角色

对象 定义
Relay 账号 未登录 -> 鉴权中 -> 已登录 -> 未登录；鉴权拒绝显式清除，不隐藏直连目标。
目标物理连接 空闲 -> 解析线路 -> 建立连接 -> mux 协商 -> 就绪 -> 恢复；鉴权失败停止自动重连。
会话通道 无需求 -> 打开中 -> 已打开 -> 已订阅；inactive 只停 body，不关通道。
Buffer 管理 未初始化 -> head 已观察 -> 在线 -> 缺口修复 -> 在线；revision 重置保留已有行。
Renderer window follow -> 用户上滚 -> reading；到底 / 重新进入 / 用户输入回到 follow。
可靠输入 空闲 -> 排队 -> 在途 -> 空闲；背压只在窗口满或高水位时进入。

状态闭合与资源释放

对象 终态与释放
Relay 账号 鉴权拒绝 / 退出到未登录；显式清除本地 account、Relay 配置与目录投影，但不隐藏 direct / Tailscale 目标。
目标物理连接 释放 / 销毁：取消心跳、关闭 transport、释放代际与 channel registry；不 kill tmux。
会话通道 已关闭 / 已销毁：只释放该通道 body、pending、input lane；sibling 通道不受影响。
Buffer 管理 session 销毁时删除 sparse truth / revision epoch / frame assembly / repair ledger；inactive 与 tab 切换不销毁。
Renderer window session 或 pane hidden 时移除 renderer 实例；不持有 buffer / transport 生命周期。
可靠输入 随 session 销毁；transport 代际变化只重置 sent 状态，不丢未确认数据。
