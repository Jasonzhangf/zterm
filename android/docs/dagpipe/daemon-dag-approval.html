Mirror diff 规则

项 规则
diff policy diff/classify/plan 都消费显式 arc.diff_policy，不作为硬编码；TUI 改写旧行时由策略决定 rewrite span 或 full resync
no-hole 默认不允许发送带洞更新；多次改动折叠为从首 changed line 到尾 changed line 的连续范围
diff trigger 仅在 authoritative mirror commit 成功后触发；client buffer-sync-request 走读已有 truth，不触发新 capture/diff
resync trigger first ready、force refresh、revision lineage 失效、range 数/span/age/backpressure 超限；resync 只发当前全窗，不发 hole

状态机与角色

对象 定义
mirror lifecycle idle -> ready -> flushing -> ready；连续失败 ready -> failed；teardown/unavailable 到 destroyed
subscriber publish no-pending -> pending-diff -> flushing -> no-pending；backpressure 进 backpressured；超限进 resync-required
角色 source_adapter 归一化；mirror_writer 提交；mirror_store 持 revision/truth；buffer_publisher 管 no-hole 计划与发送；control center 只管控制面

Phase 1 Rust core 必须落这些状态机与角色门禁；Phase 0 只先冻结静态契约。
