状态机

  • release：构建产物 → 已校验 → 已提升 → 已安装 → 已启动；摘要缺失/不匹配进失败。
  • update：空闲 → 检查中 → 可更新 → 已下载 → 已校验 → 已安装；未授权或摘要缺失进失败。
  • debug：关闭 → 待授权 → 已开启；授权拒绝/会话清理回关闭。
