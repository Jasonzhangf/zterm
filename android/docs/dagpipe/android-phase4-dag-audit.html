DAG 链路（中文业务语义）

目录与启动
  1. 请求目标窗口目录
  2. daemon 返回桌面窗口清单
  3. 浮层投影可选窗口
  4. 选择目标后请求开始流
视频接收与投影
  1. 启动捕获并按质量预算编码
  2. WebRTC 发送解码帧到客户端
  3. 客户端接收并绘制浮层
动作
  1. 触摸/鼠标动作分类
  2. 映射到 daemon 源坐标
  3. 注入输入并返回结果
质量
  1. 客户端发出质量意图
  2. daemon 调整捕获预算
  3. 捕获按新预算继续

状态机

  • 流：空闲 → 建立中 → 推流中；推流中 → 重布局中 → 推流中；建立失败/停止归入已停止终态。
  • 浮层：关闭 → 目录加载中 → 已就绪 → 连接中 → 投影中；关闭或失败回显式终点。
  • 终态：catalog-failed、capture-failed、stream-failed、input-failed。
