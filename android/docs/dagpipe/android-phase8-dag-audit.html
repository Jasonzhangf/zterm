DAG 链路（中文业务语义）

Connection Service
  1. 校验 typed 服务命令
  2. 绑定 desired target 或 release 计划
  3. 校验网络代际
  4. 重放 desired channels
  5. 建立物理 transport
  6. 维护心跳与 backoff 重连计划
  7. 投影服务快照
Notification Sessions
  1. 投影最多 3 个 connected channel action
  2. 解析 session open 深链
  3. 停止会话只脉冲匹配 action

状态机

  • 服务：idle → resolving-target → connecting → mux-ready → channels-ready → healthy；backoff-reconnect / auth-error / terminal-error 为失败终态。
  • 网络代际：旧 generation 事件拒绝；route 变更、物理关闭或认证失败终结当前 generation。
  • 通知：只投影 open 且 body 订阅的 connected channel；未知深链和未匹配停止会话保持 idle/unmatched，不阻断主连接链。
