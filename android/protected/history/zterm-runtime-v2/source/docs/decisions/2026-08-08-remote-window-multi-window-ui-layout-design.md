# Remote-Window 多窗口 UI 布局（主窗口 + 总览 + 子队列）设计方案

- 日期：2026-08-08
- 状态：**APPROVED — 2026-08-08 四项决策点：主画面=焦点窗口区域裁切放大 / 总览=主画面下方横条 / 子队列选中即放大（大项跟随选中）/ 切换仅切主画面与输入目标（不重新构图）**
- 功能块：client `remote_window_overlay`（RemoteWindowOverlay.tsx）；daemon 组合 capture 不变（合成画布推流）；wire 协议不变
- 前置：组合推流（composite pane）已交付（daemon 合成画布 + 输入映射）

## 1. 需求（用户）

多窗口串流时 UI 布局：
1. **主画面**：显示主窗口（大画面，可操作）
2. **总览画布**：显示全部窗口的分布（小窗口分割每个子窗口）
3. **固定 layout**：子窗口排布固定为 **1 大 + 3 小**
4. **可滑动队列**：窗口多（含新增）显示不下时，子窗口区变为**可横向滑动的队列**

## 2. 设计

### 2.1 数据流（不变）

- daemon 组合 capture：多窗口平铺合成一个画布推流（已有）。
- client 收到合成画布帧（frameWidth/Height = 画布尺寸）。
- client 用与 daemon 相同的布局算法（`resolveRemoteWindowCompositeLayout` 逻辑复制到 client 或共享 helper）知道每个窗口在画布内的 offset/crop。

### 2.2 UI 三区（全屏/浮层两种模式共用）

```
┌─────────────────────────────────────────────────┐
│ 主画面（大，默认主窗口，可切换）                    │
│  video 显示画布中"当前窗口区域"，裁切放大            │
├─────────────────────────────────────────────────┤
│ 总览条：整个画布缩小（全部窗口分布，可点）           │
├─────────────────────────────────────────────────┤
│ 子窗口队列：[大][小][小][小] ← 可横向滑动 →         │
│  1 大 + 3 小固定位；超出（含新增）入队尾部滑动       │
└─────────────────────────────────────────────────┘
```

- **主画面**：显示当前选中窗口在画布中的区域（video + transform 裁切放大）。默认主窗口；点击总览/子队列项切换当前窗口。
- **总览条**：一个小 `<canvas>`，每帧 `drawImage(video, 画布 → 缩略)` 显示全部窗口分布；点击窗口区域 → 主画面切换 + 输入目标切换。
- **子窗口队列**：1 大 + 3 小固定位 + 横向滚动。每个子项一个小 `<canvas>` 从画布裁切对应窗口区域（`drawImage` 到目标 rect）。新增窗口自动加入队尾；超出可视区可横向滑动。
- **输入**：主画面的触点 → 当前窗口在画布内的区域坐标（normalized 画布坐标）→ 发 daemon（daemon 已按画布→窗口映射，组合目标不变）。

### 2.3 布局细节

- 固定 layout：子队列首项"大"（如 2 倍宽）+ 3 个"小"；窗口数 ≤4 时刚好放满；>4 或新增 → 队列横向滚动（滚动条或手势滑动）。
- 画布裁切：主画面用 `video` 元素 + CSS `transform: scale + translate` 把目标窗口区域放大到主画面；或 `object-fit` + 定位。子项用 `<canvas>`（小区域 drawImage 每帧，开销低）。
- 帧同步：所有裁切共享同一 video（一个 WebRTC 流），无额外拉流。

### 2.4 交互

- 默认主画面 = 主窗口（composite 目标的主窗口）。
- 点击总览某窗口 / 子队列某子项 → 主画面切换 + 输入 sourceRect 切换（client 的 sourceRect 用该窗口的画布区域）→ 后续触点/滚动落到该窗口。
- 关闭子窗口（x）→ 从组合移除（自动增删联动）。
- 非组合（单窗口）目标：不显示总览/子队列，保持现有布局。

## 3. 实现范围

| 文件 | 改动 |
|---|---|
| `android/src/components/terminal/RemoteWindowOverlay.tsx` | 三区 UI（主画面裁切/总览 canvas/子队列）+ 切换交互 + 输入 sourceRect 按当前窗口 |
| `android/src/lib/remote-window-overlay-runtime.ts` | 布局算法共享（client 侧 resolve composite layout）+ 当前窗口 state |
| 测试 | 布局/裁切坐标/切换逻辑 |

## 4. 验收

1. 微信多窗口（主 + 图片预览）串流：主画面显示主窗口，总览显示两个窗口分布，子队列 1 大 1 小
2. 点击预览窗口子项 → 主画面切到预览窗口，输入落到预览窗口
3. 新增窗口 → 自动加入子队列尾部，可横向滑动查看
4. 单窗口目标：布局不变（无总览/子队列）
5. type-check 0、测试全绿、build:android + OTA
